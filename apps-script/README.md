# Apps Script de pedidos

Código del menú **Innova** de la planilla de pedidos. No corre en el sitio: se pega en
*Extensiones → Apps Script* de la planilla.

- `Pedidos.gs` — menú, alta de pedidos, recontacto y configuración de la planilla.
- `PanelPedido.html` — panel lateral de "Nuevo pedido" (en el editor se crea como archivo HTML
  llamado `PanelPedido`).

Instalación y circuito completo: [`docs/pedidos-google-sheets.md`](../docs/pedidos-google-sheets.md).

Si cambiás algo acá, volvé a pegarlo en el editor de Apps Script: no se sincroniza solo.
